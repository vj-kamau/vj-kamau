# 💻 Laptop Sales Analysis

## 📌 Project Overview

This project analyzes a laptop sales dataset to explore product characteristics, pricing patterns, and differences across laptop brands and specifications.

The project focuses on transforming raw laptop data into a structured dataset and using Excel to perform analysis and create a dashboard that communicates the key findings.

## 🎯 Project Objectives

The analysis aimed to:

* Examine laptop prices across different brands and laptop types.
* Identify patterns in laptop specifications and pricing.
* Analyze the relationship between specifications such as RAM, storage, CPU speed, screen size, and price.
* Compare laptop brands based on pricing.
* Identify patterns that could help customers or businesses understand laptop pricing.

## 📂 Dataset

The original dataset contained **1,303 laptop records** and **12 variables**.

The variables included information such as:

* Company
* Laptop type
* Screen size
* Screen resolution
* CPU
* RAM
* Storage
* GPU
* Operating system
* Weight
* Price

## 🧹 Data Cleaning & Transformation

The raw dataset required cleaning and transformation before analysis.

The cleaned dataset contains **1,274 records and 17 variables**.

Key transformations included:

* Extracting CPU brand and CPU type.
* Separating CPU speed from the CPU description.
* Converting RAM values into numerical values.
* Extracting storage capacity.
* Identifying storage types such as SSD and Flash Storage.
* Extracting additional storage information where applicable.
* Converting laptop weight into numerical kilograms.
* Removing records that were not suitable for the final analysis.
* Standardizing variables for analysis.

The cleaning process was designed to make the dataset easier to analyze using Excel formulas, PivotTables, and visualizations.

## 📊 Analysis

The analysis explored several aspects of the laptop market, including:

* Total laptop price value.
* Average laptop price.
* Laptop prices by company.
* Laptop prices by laptop type.
* Pricing across CPU types.
* Pricing across storage types.
* Pricing patterns based on laptop specifications.

PivotTables were used to summarize the data and identify patterns across different categories.

## 📈 Dashboard

An Excel dashboard was created to present the major findings from the analysis in a more accessible and interactive format.

The dashboard brings together key metrics and visualizations to help users explore laptop pricing and specifications.
